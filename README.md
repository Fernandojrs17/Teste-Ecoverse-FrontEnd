# Teste Front-End Jr - Econverse

Projeto pronto em React + TypeScript + Sass.

## Como executar

1. Abra esta pasta no VS Code.
2. Abra o terminal dentro da pasta.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra o endereço mostrado pelo Vite no navegador.

## O que já está funcionando

- React + TypeScript
- Sass
- Consumo do JSON oficial da Econverse
- Cards de produtos
- Modal ao clicar no produto
- Informações do modal vindas do JSON
- Formatação de preço em Real
- Layout responsivo
- HTML semântico
- SEO básico

O endpoint usado está em `src/services/products.ts`.
